# Chocolate Sales Analysis – Excel

## Project Overview
This project analyzes chocolate sales data using Microsoft Excel. The objective is to understand sales performance across different countries, products, sales representatives, and months through data summaries and Pivot Tables.

The analysis helps identify sales trends, compare country-wise performance, and evaluate the contribution of different products and sales representatives.

## Dataset Overview
The dataset contains **1,094 sales records** covering January to August 2022.

It includes the following columns:

| Column | Description |
|---|---|
| Sales Person | Name of the sales representative |
| Country | Country where the sale was made |
| Product | Chocolate product sold |
| Date | Date of the transaction |
| Day Name | Day of the week |
| Month | Month of the transaction |
| Amount | Sales amount |
| Boxes Shipped | Number of boxes shipped |

## Tools Used
- Microsoft Excel
- Pivot Tables
- Data Analysis
- Data Summarization

## Analysis Performed
The workbook includes sales summaries and Pivot Table analysis covering:

- **Sales Representative Analysis:** Comparison of sales performance by representative.
- **Country-wise Analysis:** Revenue and boxes shipped across six countries.
- **Product Analysis:** Comparison of sales across different chocolate products.
- **Monthly Sales Analysis:** Month-wise sales and shipment trends.
- **Country and Sales Representative Analysis:** Comparison of sales representatives across different countries.

## Key Insights
Based on the available dataset:

- Total recorded sales amount: **6,183,625**
- Total boxes shipped: **177,007**
- Total sales records: **1,094**
- Australia recorded the highest sales amount, with **1,137,367**.
- The dataset covers six countries: Australia, Canada, India, New Zealand, UK, and USA.
- The dataset contains 22 chocolate products and 25 sales representatives.

*Note: The currency for the Amount column is not specified in the source dataset.*

## Project Structure
- `Chocolate Sales (1).xls` – Original Excel workbook containing the sales dataset, Pivot Table summaries, and Dashboard worksheet.

## Conclusion
This project demonstrates how Excel can be used to organize, summarize, and analyze sales data. By using Pivot Tables and different business dimensions, the analysis provides an overview of sales performance and supports data-driven business decisions.
